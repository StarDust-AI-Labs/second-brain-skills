# 第二大脑宣传片 V2 诊断

## 结论

现有版本不是“质感差一点”，而是尚未形成完整宣传片。它目前更像两个视觉实验：一个信息卡片收集镜头，以及同一批卡片坍缩成乱团的镜头。产品的独特能力、完整价值链和最终成果都没有被呈现。

## 现有版本的核心问题

### 1. 产品叙事缺失

- 只表现了“收藏很多”和“越管越乱”。
- 没有出现 `second-brain-hub`、意图路由、方法论编排、本地 Markdown、Obsidian 或安全门控。
- 没有呈现“捕获 → 组织 → 提炼 → 表达”的完整闭环。
- 没有回答观众最关心的问题：它与普通笔记工具、AI 摘要工具有什么不同。

### 2. 视觉隐喻单一

- 两个镜头都依赖卡片堆积，镜头之间缺少视觉升级。
- 卡片没有真实语义，只是重复的占位线条，无法建立产品可信度。
- 第二镜头主体尺寸过小、亮度过低，大面积空场削弱了冲击力。

### 3. “科技感”停留在模板层

- 深蓝背景、青色描边、四角 HUD、扫描线和等宽英文是通用科技模板语言。
- HUD 标签与产品行为没有关系，多数只是装饰。
- 英文副标题的信息价值低，反而分散中文主张。

### 4. 高级感不足

- 画面层级主要依赖发光描边，没有材质、空间、镜头景深和光线叙事。
- 卡片密度高但细节重复，形成的是“杂乱”，不是“精密”。
- 构图缺少连续摄影机运动和视觉焦点转移，成片容易像 PPT 动效。

### 5. 工程尚未形成整片

- 规划为 35 秒、6 个镜头，但只完成了两个镜头。
- `Promo` 合成实际上只注册了第一个 3 秒镜头。
- 没有统一时间线、转场、音乐、音效与最终 CTA。

## 可复用资产

- `theme.ts` 中的深色基底、青色与暖金色角色分工。
- `mulberry32` 确定性随机函数。
- 信息碎片的生成逻辑，可改造成带真实语义的数据薄片。
- HUD 的扫描揭示、细线与微弱数据流，可降级为辅助层。
- 两张概念海报中的“黑色晶体核心”“知识网络”“从噪声到成果”视觉母题。

## V2 创意原则

1. 每个镜头必须表达一个产品事实。
2. HUD 只做状态反馈，不做主体。
3. 科技感来自空间、材质、光线和精密运动，不来自堆满界面元素。
4. 青色负责输入、路由与连接；暖金只在知识成为成果时出现。
5. 信息碎片必须具有真实类型：语音、网页、文件、灵感、笔记、项目与创作产物。
6. 画面始终沿着“噪声 → 秩序 → 理解 → 创造”升级。
