# 第二大脑产品宣传片 V2 分镜

## Video direction

- 时长：35 秒
- 画幅：1920 × 1080，16:9，30fps
- 语言：中文
- 声音：无旁白；电影感电子氛围音乐 + 精密 UI 音效 + 低频冲击
- 核心主张：让知识从收藏走向创造
- 视觉母题：冷黑晶体知识引擎、神经网络、数据薄片、暖金成果
- 色彩：黑曜石黑 / 深空蓝 / 电光青；暖金仅用于“成果诞生”
- 字体：中文无衬线粗体 + 紧凑等宽英文标注
- 摄影机：持续推进、穿越、环绕；避免平面卡片逐个淡入

## Shot 01 — 信息洪流

- 时间：00:00–00:04
- 目的：用高密度开场建立真实痛点。
- 画面：黑场中依次划过语音波形、网页链接、PDF、聊天灵感和视频片段。它们从四周冲入，短暂可读，随后堆积成失控的信息风暴。
- 屏幕文字：`你保存了很多。`
- 运动：快速掠过 → 镜头拉近风暴核心 → 突然静止半拍。
- 声音：细碎输入提示音、连续上升的数字噪声、结尾低频抽空。
- 复用：现有碎片生成和确定性随机布局，但重做材质与真实内容。

## Shot 02 — 收藏不是知识

- 时间：00:04–00:08
- 目的：一句话击中问题，并与旧版概念形成联系。
- 画面：信息风暴被压成一颗暗淡、无连接的灰黑核心；周围漂浮着未处理、未关联、未输出的状态标记。
- 屏幕文字：`但收藏，不等于学会。`
- 辅助标注：`UNPROCESSED / 247`、`CONNECTIONS / 0`、`OUTPUT / 0`
- 运动：镜头缓慢逼近，核心内部出现第一束青色扫描光。
- 声音：心跳般低频脉冲，扫描启动声。

## Shot 03 — Hub 苏醒

- 时间：00:08–00:13
- 目的：第一次明确展示产品身份和核心差异。
- 画面：暗核裂开并重组为黑色多面晶体；中央 `second-brain-hub` 点亮，八条意图路由环绕展开：灵感、网页、提炼、创作、收件箱、回顾、搜索、诊断。
- 屏幕文字：`一个入口，理解你的意图。`
- 辅助标注：`SECOND-BRAIN HUB / ONLINE`
- 运动：晶体组装 → 环形路由依次点亮 → 镜头从正面转为三分之二侧面。
- 声音：晶体锁合、八次轻量路由点击、系统上线提示音。

## Shot 04 — CODE 成为可执行工作流

- 时间：00:13–00:21
- 目的：把方法论从口号变成可见的执行链。
- 画面：摄影机穿入晶体内部，连续经过四个空间阶段，而不是四张并列卡片：
  1. Capture：语音、链接、文件被筛选成有价值的信息薄片；
  2. Organize：薄片沿 PARA 轨道归入项目、领域、资源、存档；
  3. Distill：正文被逐层高亮、压缩为摘要和核心观点；
  4. Express：多个知识节点连接成文章大纲、视频脚本和项目方案。
- 屏幕文字：`方法论，不只告诉你怎么做。` → `Agent 直接替你推进。`
- 运动：一镜到底式穿越，每个阶段约 2 秒，形态持续演化。
- 声音：筛选、归档、压缩、连接四组具有区别的精密音效。

## Shot 05 — 从一句话到真实结果

- 时间：00:21–00:28
- 目的：展示真实使用体验，而不是抽象能力。
- 画面：左侧出现用户输入，右侧展示系统执行与本地结果：
  - `记一下：这个选题可以做成视频` → 自动归属项目并写入 Markdown；
  - `保存这篇文章` → 提取正文、摘要、PARA 分类；
  - `帮我写一个大纲` → 检索旧笔记并生成可继续创作的结构。
- 屏幕文字：`你只负责表达意图。`
- 次级文字：`路由 · 提炼 · 关联 · 写入，由 Agent 完成`
- 运动：三条指令依次输入，但上一条结果保留并成为下一条的素材，形成连续积累感。
- 声音：键入、路由确认、文件落盘、知识连接。

## Shot 06 — 知识结晶

- 时间：00:28–00:32
- 目的：情绪与视觉高潮。
- 画面：前面形成的知识节点和信息薄片向中央聚合，冷青网络逐渐转为暖金，凝结成一颗切割清晰的知识晶体；晶体内部依次闪现文章、方案、视频脚本等成果轮廓。
- 屏幕文字：`知识管理的终点，不是收藏。`
- 下一拍文字：`是创造。`
- 运动：聚合加速 → 金色爆发但保持克制 → 晶体稳定旋转。
- 声音：低频上升、晶体凝结、温暖而短促的高潮音。

## Shot 07 — 品牌收束

- 时间：00:32–00:35
- 目的：留下清晰品牌与定位。
- 画面：晶体缩小成为品牌标记，背景只保留极弱的知识网络呼吸。
- 主标题：`第二大脑 · Skill 生态`
- 副标题：`AI Agent 驱动的个人知识工作流系统`
- CTA：`让知识，从收藏走向创造`
- 辅助标注：`OBSIDIAN / MARKDOWN / AGENT-NATIVE`
- 运动：标题精准锁定，晶体轻微呼吸，最后干净切黑。
- 声音：品牌确认音 + 极短尾韵。
