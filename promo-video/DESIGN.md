# 设计规范 · 第二大脑宣传片（HUD 未来主义）

> 本文档是全片美术方向的唯一权威来源（single source of truth）。
> 任何镜头代码必须先符合本规范，再谈实现。改方向先改这里。

## 0. 一句话质感
**「一块精密仪器的人机界面，在冷静地运转」** —— 不是烟花，是仪表盘。
科幻 FUI 的「炫」来自**精密与秩序**，不是来自霓虹乱闪。

## 1. 三条铁律（决定高级感，违反即廉价）
1. **单色光源**：全片只有「青 `#00E5FF`」一束主光，暖金 `#FFB74D` 只留给「大脑/宝石/升华」做点缀。绝不彩虹渐变、不多色乱闪。
2. **网格对齐**：一切元素吸附到 8px 网格与安全边距。拒绝「居中万金油构图」。关键信息走「左对齐」或「占满安全框的版式」，不是全部堆画面正中。
3. **细线条 > 大色块**：HUD 的骨架是 1px 细线、刻度、括弧、扫描线，不是圆角发光卡片。发光只做「描边/文字辉光」，绝不做大面积弥散光晕。

## 2. 色彩（沿用 theme.ts，但收紧用法）
- 底：`bgDeep #070A1A` / `bgBase #0A0E27`，叠加 5% 扫描线纹理
- 主光：青 `cyan`，只用于：数据流、连线、强调文字、交互焦点
- 点缀：暖金 `warmGold`，只用于镜头3/5（苏醒、宝石）
- 痛点段（镜头1/2）：去饱和冷灰 `shard`，**只留一丝青**做「本可更好」的暗示
- 失活态：grayscale + 降亮度，**不加红光**（红光=报警，留给真正的「卡死」瞬间单点使用）

## 3. 字体排版（最大的升级点）
| 用途 | 字体 | 处理 |
|---|---|---|
| 大标题（中文） | Noto Sans SC 900 | 字号 96-160，字距收紧 -0.02em，左对齐或出血版式，**不居中** |
| 英文点缀 | JetBrains Mono / Cinzel | 全大写、字距 0.3em、小号 18-24、作为「标注/坐标」而非副标题 |
| 数据/编号 | JetBrains Mono | 等宽数字、前导零 `01` `02`，做 HUD 刻度感 |

原则：**英文小字是「界面标注」，不是「副标题翻译」**。去掉「大中文 + 一行分散英文」的 PPT 结构。

## 4. HUD 组件库（全片复用，先做这些再谈镜头）
- `HudFrame`：画面四角的 1px 括弧取景框 + 刻度
- `Scanlines`：5% 透明度水平扫描线（叠加在最顶层）
- `DataStream`：横向/纵向流动的字符流（等宽字体，青色，低透明）
- `HudTag`：左上角 `// SYS.LOG_01` 式标注，等宽、前置 `//`、带闪烁光标
- `Reticle`：聚焦用的十字/圆环准星（镜头2 卡死、镜头3 苏醒用）
- `GlowLine`：1px 发光细线（代替粗描边卡片）
- 碎片 `Shard`：保留，但**去掉发光描边**，改为「冷灰线稿 + 1px 青描边」，更像「未激活的数据残片」

## 5. 动效编排（HUD 的节奏感）
- **扫描进场**：元素不是 spring 弹出，而是「一条扫描线扫过 → 内容逐行点亮」
- **逐字/逐行打字**：HUD 文字用打字机 + 光标，不用整段 fade
- **数据流动**：背景永远有低速流动的字符/网格，制造「系统在运转」的生命感
- **故障 glitch**：镜头2 卡死用「1-2 帧的位移/色差 glitch」，不是持续震颤
- 缓动：沿用 `easingOut [0.16,1,0.3,1]`，但幅度收敛（overshoot 1.12 → 1.04，HUD 是精密不是弹跳）

## 6. 各镜头改造要点
- **镜头1 收藏≠学会**：碎片不再「发光悬浮」，改为「从四周被吸入一个收集框」的故障堆积。字卡走左对齐出血版式。
- **镜头2 越管越乱**：乱麻收敛为「被准星锁定的缠绕核」，卡死瞬间用 glitch。去掉持续震颤。
- **镜头3 苏醒**：唯一允许暖金的镜头。青光神经网络点亮 + 暖金光核苏醒，是全片情绪顶点。
- **镜头4 CODE 四步**：HUD 分屏，四步用 `01-04` 编号 + 发光细线流程，最考验网格。
- **镜头5 宝石**：暖金主调，碎片坍缩凝练成一颗切割宝石。
- **镜头6 CTA**：极简，一块居中的「按钮式」HUD 面板 + 一句主张。

## 7. 验收基线
做完每个镜头，对照本文档第 1 节三条铁律逐条打勾，任何一条违反就返工。
